# V10 — изменения и проверки

## Изменено

- Настраиваемые KnownProxies/KnownIPNetworks в ForwardedHeaders. Приложение не читает IP из заголовков вручную. Без списка доверия заголовки игнорируются.
- CORS: точные origins, GET/POST, Content-Type/Authorization.
- Уникальные типы шести услуг; Estimate в меню и секции; контекст к трём проектам без неподтверждённых моделей автомобилей.
- Общая дата America/New_York для бронирования и счётчика админки. Верхняя граница — календарный месяц с корректировкой последнего дня.
- Календарь en-US/MM/DD/YYYY: кнопки месяца, отключённые недоступные даты, выбор клавиатурой, закрытие Escape/при уходе фокуса.
- US phone, состояние отправки, блокировка повторного submit, отдельный экран успеха с телефоном, датой, услугой и Back home.
- Удалён неиспользуемый lib/whatsapp.ts.
- Заявки перенесены на PostgreSQL/Npgsql: приватная схема, SQL создания, импорт старого JSONL, healthcheck БД, Dockerfile для Railway.
- Hero и About, изображения и анимация фар не изменялись в V10.

## Проверено

- Next.js production build, TypeScript: успешно.
- .NET 10 publish Release: успешно.
- Интеграционная проверка API с локальным PostgreSQL-движком PGlite через TCP: schema repeatability, запрет anon, проверка полей, запись и чтение, авторизация, CORS, лимит, игнорирование подставленных заголовков и принятие заголовка от явно доверенного прокси, повторный импорт, откат ошибочного импорта, сохранение после перезапуска backend, безопасный 503 при ошибке БД.
- React/DOM-проверки: Нью-Йорк около полуночи, конец месяца/високосный год, выбор календаря, один активный запрос, payload, загрузка и экран успеха.

## Что остаётся настроить владельцу

Облачные проекты, SQL в Supabase, секреты, список доверенных ingress IP/CIDR, домены, CORS и бэкапы. Эти действия не выполнены в аккаунтах пользователя. TLS к реальному Supabase и работа Railway ingress требуют проверки после настройки; локальный тест их не заменяет. Полная визуальная проверка в браузере не завершена.

Полная инструкция — DEPLOY_RU.md.
